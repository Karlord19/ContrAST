% Abstract (recommended length around 80-200 words; this is not a copy of your thesis assignment!)
\def\Abstract{%
Students submit their programming assignments to ReCodEx, an online system that automatically evaluates code correctness and performance, and detects identical text segments to flag potential plagiarism.
However, direct text matching is not sufficient for slightly modified code.
We propose a syntax-driven plagiarism detection tool that analyzes the similarity of code fragments.
The tool is based on an abstract syntax tree representation of the code and a comparison algorithm that computes a similarity score between code fragments.
It generates a report with potentially plagiarized code fragments and sends it to ReCodEx, where the results are visualized for the teachers.
The system remains open to further improvements, such as integrating new similarity metrics or extending support to additional programming languages.
}
