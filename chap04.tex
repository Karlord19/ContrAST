\chapter{atc}\label{sec:atc}

atc is a C++ tool for parsing C/C++ code into comparatree, primarily developed as part of a research project preceded by this thesis, and later slightly changed to fulfill new interface requirements of comparatree and the whole project.
See the documentation of atc in the research project for more details.

atc would also be used in another diploma thesis, that needs semantic information from the code.
This led to choosing clang/LLVM as the parser, the libtooling library \cite{libtooling} to be precise, which is a widely used and well-maintained library for building tools that analyze and transform C/C++ code.

The main structure of atc is standard for a clang-based tool.
We define a class that inherits from \verb|ASTConsumer|, which accepts a translation unit and processes it.
The processing is done by a visitor class that inherits from \verb|RecursiveASTVisitor|, which provides a convenient way to traverse the abstract syntax tree (AST) generated by clang and visit each node.
We only need to override the concrete visit methods for the AST nodes that we want to capture in comparatree, collect the interesting information from the AST nodes, and build the corresponding comparatree structures.
